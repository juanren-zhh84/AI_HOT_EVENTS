

```bash
cd /opt/ai-hot-events
git pull
# 进入项目目录
```

**启动**

```bash
docker compose --env-file .env.production up -d mysql
# 启动 MySQL 容器

sudo systemctl start ai-hot-events
# 启动 FastAPI 后端服务

sudo systemctl start nginx
# 启动 Nginx 反向代理
```

**重启**

```bash
sudo systemctl restart ai-hot-events
# 重启后端，修改 .env 或代码后常用

sudo systemctl restart nginx
# 重启 Nginx，修改 nginx 配置后使用

docker compose --env-file .env.production restart mysql
# 重启 MySQL 容器
```

**查看状态**

```bash
docker compose --env-file .env.production ps
# 查看 MySQL 容器状态

sudo systemctl status ai-hot-events --no-pager -l
# 查看后端服务状态

sudo systemctl status nginx --no-pager -l
# 查看 Nginx 状态

sudo ss -lntp | grep -E ':3306|:8000|:8080'
# 查看 MySQL、FastAPI、Nginx 端口监听
```

**实时日志**

```bash
sudo journalctl -u ai-hot-events -f -n 100
# 实时查看后端日志

docker compose --env-file .env.production logs -f mysql --tail=100
# 实时查看 MySQL 容器日志

sudo tail -f /var/log/nginx/error.log
# 实时查看 Nginx 错误日志

sudo tail -f /var/log/nginx/access.log
# 实时查看 Nginx 访问日志
```

**健康检查**

```bash
curl http://127.0.0.1:8000/api/v1/health
# 服务器本机直连 FastAPI 检查

curl http://127.0.0.1:8080/api/v1/health
# 服务器本机走 Nginx 检查
```

**停止**

```bash
sudo systemctl stop ai-hot-events
# 停止后端

sudo systemctl stop nginx
# 停止 Nginx

docker compose --env-file .env.production stop mysql
# 停止 MySQL 容器，不删除数据
```
